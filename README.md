# NewCoder 刷题笔记

开始新题前读取[协作工作流](STUDY_WORKFLOW_PROMPT.md)，使用[批次工具](工具/批次工具.py)跨专题查找候选并定位原题；按需查阅[全项目题目总索引](题目总索引.md)和专题索引，核对完整题干与全部选项。

各专题历史题每份最多30题，后续新卷按专题和批次归档。第一遍在对话中完整讲题；第二遍收到官方解析后归档并更新索引，检查后按阶段提交本地 Git。

复习时可查看[复习入口](复习入口.md)。索引检查与候选搜索：`python3 工具/索引工具.py check`；`python3 工具/索引工具.py search "题干关键词"`。重建先预览，具体见[工作流](STUDY_WORKFLOW_PROMPT.md)。
