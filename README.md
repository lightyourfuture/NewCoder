# NewCoder 刷题笔记

开始新题前读取[协作工作流](STUDY_WORKFLOW_PROMPT.md)，用[全项目题目总索引](题目总索引.md)搜索候选，再读目标专题的 `README.md` 和 `题目索引.md`，只打开匹配的小文件核对完整题干与全部选项。

各专题历史题每份最多30题，后续新卷按专题和批次归档。第一遍在对话中完整讲题；第二遍收到官方解析后归档并更新索引，检查后按阶段提交本地 Git。
