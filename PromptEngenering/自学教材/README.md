# 提示词工程：从理解到独立应用

先读[教材 PDF](../../output/pdf/提示词工程_从理解到独立应用.pdf)，再用浏览器打开[练习台](练习台/index.html)。希望复制到其他设备时，使用[离线自学包](提示词工程_离线自学包.zip)：解压后打开“开始学习.html”，同目录带有 PDF。

正文约两万字，11 章，从任务表达与示例开始，逐步进入输出、采样、推理、工具、证据、上下文、评测、安全和综合迁移。采用康奈尔式页侧回忆线索，配有贯穿案例、章末原创练习与解释、题目对照和 21 项研究/文档导航。不是逐题抄写解析。

练习台支持：

- 阅读教材、标记章节进度，跳转相应章节原题。
- 顺序、随机、未做、待复习；搜索题干和选项。
- 单选、多选，选项位置打乱后映射回原始答案；提交后再看解析。
- 自评把握程度、写理由；猜对也复习。简易间隔为有把握答对后 1、3、7 天；错题或没把握的题立即保留。
- 10 题、20 题或全题自测，交卷前不显示答案；未作答单独列出。
- 浏览器本地保存、JSON 导出与导入。没有账号、云同步或模型 API。

题目范围为现有 `PromptEngenering/题目/` 的 101 道独立题目，以及 `PromptJudge` 的 1 道提示注入题。邮件风格题的历史复习与锚点别名不另计。其他专题仅含相近术语的题没有被无限扩入本次练习库。四个条目已存官方答案与解析，其余按历史结论呈现，不冒充官方材料。原题文件保持原处。

分隔符防注入、示例顺序与标签、JSON Mode、校准、Maieutic 等表述在教材和练习台另有核对说明。原题与已有官方结论不静默改写。

## 使用与便携

HTML 没有网络依赖，桌面浏览器通常可直接打开；本次交互验收使用本机 HTTP 地址，内置预览器限制 file 协议，未在其中验证文件方式。某些移动文件预览器不支持完整网页功能，应改用浏览器或本地 HTTP 服务。记录跟随浏览器及访问地址：文件方式和 HTTP 方式使用不同存储空间，跨设备或改变访问方式前请导出备份。隐私模式或浏览器禁止存储时，及时导出，界面会提示临时使用。

需要 HTTP 访问时，在仓库根目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，再访问 `http://127.0.0.1:8765/PromptEngenering/自学教材/练习台/index.html`；使用结束按 Ctrl+C 停止。默认仅本机可访问，不设置后台服务。

## 维护与重建

唯一手工教材源为[教材 Markdown](源文件/教材.md)、[前言](源文件/前言.md)和[课程配置](源文件/课程配置.json)。练习台自动从正式题目文件生成，生成 HTML 与 ZIP 是交付物，不手工维护第二份题库。

在仓库根目录执行：

```sh
python3 PromptEngenering/自学教材/工具/构建.py
latexmk -norc -cd -xelatex -interaction=nonstopmode -halt-on-error PromptEngenering/自学教材/构建/main.tex
python3 PromptEngenering/自学教材/工具/核验.py
python3 PromptEngenering/自学教材/工具/打包.py
```

构建需要 Python 3、Pandoc、XeLaTeX / latexmk。版式使用本机的 Songti SC、Heiti SC、Times New Roman、Arial、Menlo；在其他系统重建时需在[版式](源文件/版式.tex)中换成可用字体。交付 PDF、HTML 与 ZIP 不要求安装这些构建工具。`构建/` 只保存可重新生成的中间产物，已忽略。

核验工具独立对照全部题干、每个选项、四份官方解析、历史复习、章节映射与缺字/溢出日志。浏览器验收覆盖提交、单选、多选漏选与选全、乱序映射、猜对复习、自测恢复/交卷、未作答统计、导入导出及手机/桌面布局；PDF 全页渲染检查。浏览器自动保存和间隔规则属于学习辅助，不是已证明的个人掌握程度评估。
