# 工作记忆

## 项目用途

这个项目用于学习计算机和 AI 相关知识，长期记录刷题过程、题目解析、错题、知识点总结和协作工作流。

## 当前协作约定

- 用户会发送牛客、力扣、知识星球等平台的题目。
- 题目笔记分两遍（2026-10-16 起的现行规则，详见 `STUDY_WORKFLOW_PROMPT.md`）：第一遍只在对话中完整展示题型、原题号、题干、全部选项并给出独立解析，不写该题正式笔记；第二遍收到官方答案与官方解析后才正式归档，顺序为原题与选项 → 官方答案原文 → 官方解析原文 → 助手核对与纠错 → 补充与扩展 → 通俗大白话解释 → 易错点 → 知识点总结 → 本次复习记录。
- 每个专业术语都要解释，前后题标准一致，不用“同上”省略本题的基础说明。
- 三种信息必须分开标注、不能互相冒充：官方答案与解析（原文）、助手首遍独立判断（首遍未核实时不补造）、用户本次作答。
- 原题和官方解析完整保留内容；可整理浏览器复制格式、修复明确的公式排版，实质纠错在“核对”区另列，不能删减题面或改变官方结论。
- 当前默认学习专题是大模型概念，题库多为单选 20 道 + 多选 10 道（2026-10-16 起常见 1—28 单选、29—30 多选，以原题为准）；用户未明确切换专题时归档到 `LLMConcept/NOTES.md`。
- 用户如果开始学习其他板块，会明确说明，例如 Agent、提示词工程、RAG、Prompt 判断、微调等；届时再切换归档目录。
- 查重跨专题进行；完全重复题更新原条目并在“本次复习记录”追加批次，相似题不误合并；批次标识按用户说法记录（如“2026-10-16 第3组”“2026-10-17 Gemini第1轮”）。
- 当前仅由 Codex 使用本地模式继续处理（2026-10-19 用户明确指定）；旧网页模式仅作历史兼容，不主动改用 Gemini、DeepSeek 或委派其他 Agent。
- 用户要求：展示数学公式时使用专门、直观的展示方式，优先用 LaTeX 块公式和分步推导。
- 只修改用户授权的文件和题目段落，不新增原题副本等辅助文件。2026-10-19 起用户已授权验证通过后按实质阶段直接提交本地 Git，记录执行者、来源、阶段和检查结果；不自动推送、不设后台任务。项目工作记忆仍只在用户明确要求或明确包含其修复时更新，不自动修改全局记忆。
