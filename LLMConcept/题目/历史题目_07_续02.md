## 2026-10-16 第2组 题22 自监督预训练的目标

来源:用户提供题目及官方答案,官方解析.

题型:单选题

题号:2026-10-16 第2组 22

平台知识点:大模型概念

归档阶段:第二遍.

与上一组自监督预训练题,本组第 2 题相关.

题目:

> 关于大模型预训练阶段的自监督学习范式,以下描述最准确的是?

选项:

- A. 通过预测文本中的掩码token(如[MASK])等目标来学习通用语言规律
- B. 需要大量人工标注的分类/问答数据作为核心训练样本
- C. 仅适用于图像分类等特定任务的小模型训练
- D. 核心依赖强化学习(RL)优化模型的决策逻辑

官方答案:
A

官方解析:
自监督学习在大型预训练模型(如BERT或GPT)中,核心范式是通过预测掩码token(如[MASK])等目标学习通用语言规律(选项A正确).选项B错误,因为自监督学习不需要大量人工标注数据;它使用未标注数据自生成任务.选项C错误,因为自监督学习不仅适用于图像分类或小模型,也广泛用于语言模型等大模型预训练.选项D错误,因为自监督学习的核心不是强化学习(RL);RL通常用于后微调阶段(如RLHF),而非预训练.

核对补充:
首遍助手判断:A; 官方答案:A
答案与首遍助手判断一致,官方解析的核心结论可作为本题解题依据.

补充与扩展:
BERT 常用 MLM,GPT 类模型通常用因果语言建模;选项 A 中的"等目标"允许这些不同形式,不能记成所有模型都使用 [MASK].

通俗大白话解释:
监督信号由原始文本和预设任务自动构造,例如遮词重建或预测下一个 token,不用人工逐条另写答案.

易错点:

- B:大量人工标注不是这种预训练的必要核心.
- C:不限图像或小模型.
- D:核心不是强化学习.

知识点总结:

- 自监督:从数据自身构造学习目标.

## 2026-10-16 第2组 题23 KV Cache 复用历史键值

来源:用户提供题目及官方答案,官方解析.

题型:单选题

题号:2026-10-16 第2组 23

平台知识点:大模型概念

归档阶段:第二遍.

与既有 KV Cache 主要目的题相似.

题目:

> 大模型推理过程中KV缓存的主要作用是?

选项:

- A. 减少硬盘IO开销
- B. 避免重复计算注意力键值
- C. 压缩模型参数量
- D. 提升训练稳定性

官方答案:
B

官方解析:
KV缓存(Key-Value缓存)在大模型推理过程中的主要作用是避免重复计算注意力机制中的键(Key)和值(Value)向量.在Transformer模型的推理阶段,特别是自回归生成(如文本生成)中,KV缓存存储已生成的键值对,从而避免在每个时间步重新计算之前的键值,提高推理效率并减少计算开销.选项A错误,因为KV缓存主要在内存中进行操作,目的是减少计算开销,而非硬盘IO开销;选项C错误,因为KV缓存是缓存中间状态,不涉及模型参数的压缩;选项D错误,因为题目指定的是推理过程,而提升训练稳定性与训练过程相关,KV缓存在训练中通常不使用.

核对补充:
首遍助手判断:B; 官方答案:B
答案与首遍助手判断一致,官方解析的核心结论可作为本题解题依据.

补充与扩展:
缓存并没有取消全部注意力计算:新 Query 仍需与历史 Key 计算关系;缓存也会随上下文增长而占用更多显存.

通俗大白话解释:
把历史 token 算好的 Key,Value 保存,生成后续 token 时直接复用,避免每一步重新处理相同前文.

易错点:

- A:主要不是减少硬盘读写.
- C:缓存中间状态不改变模型参数量.
- D:主要用于推理加速,不是稳定训练梯度.

知识点总结:

- 历史 K,V 算过就存,下一步直接复用.
